# Muntaha Meem — Full-Stack Developer Portfolio

A responsive dark portfolio starter built with **Next.js App Router, React, TypeScript, and custom CSS**.

## Requirements
- Node.js 20.9 or newer
- npm

## Run locally
```bash
npm install
npm run dev
```
Open http://localhost:3000

## Production build
```bash
npm run build
npm start
```

## Before publishing
1. Replace `hello@example.com` with your real contact email.
2. Update GitHub and LinkedIn links in `app/page.tsx`.
3. Replace the illustrative project concepts with real projects, links, and screenshots.
4. Update the Journey section with verified experience, education, and achievements.
5. The contact form is a front-end demo only. Connect it to an API route or a service such as Resend before using it to receive messages.
6. Add your own résumé PDF to `public/` and add a Resume link if you want a downloadable CV.

## Suggested deployment
Deploy to Vercel by importing the repository. The project is static-friendly and does not require a database unless you later add dynamic features.
